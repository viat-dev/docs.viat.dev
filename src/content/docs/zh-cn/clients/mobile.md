# 原生客户端操作

原生客户端用于**日常运维**——它不是跑在设备上的 Viat 服务端,也不替代
控制台的全部编辑器。本页对应 **0.1 客户端版本线 + server 1.1.0**。Mac
与手机共用 Home/Assistant/Settings 界面,但原生存储、通知注册与 Widget
行为因平台而异;下文引用的是当前英文界面标签。

通过部署方批准的渠道获取正确签名产物;平台前提见
[客户端安装](../installation/clients.md)。本手册**没有**建立公开
App Store/TestFlight/DMG 下载渠道;开发 IPA 不代表任意 iPhone 都获准安装。

## 连接正确的实例和身份

设备必须能访问实例,并具备有效平台账号、已激活部署与项目成员资格;
项目终端用户令牌**不是**平台登录。Mac 能访问内网,不代表内网之外的
手机也能。

1. 打开实例选择器或 **Settings → Instances** 添加部署。
2. 输入基础 URL:包括运维配置的反代前缀,**不包括** `/ui/` 或
   `/p/<slug>`;远程部署用 HTTPS;**不要**在 URL 里嵌密码或 bearer。
3. 保存并选择实例,用密码/MFA 或已配置的 SSO 登录;要求 MFA 登记时
   完成支持的流程,不要尝试绕过。
4. 在 Home 或 **Settings → Project** 选择可访问项目——这是**同一个**
   全应用项目选择,不是两个互不关联的设置。
5. 批准任何写操作前,核对实例名称、部署 URL 与项目。

| 实例字段 | 规则与影响 |
| --- | --- |
| Name | 可选,去首尾空白;留空用主机名派生标签;显式名称 ≤32 字符。重命名 ≠ 换服务端或新建登录。 |
| Base URL | 必填,带主机名的有效 `http`/`https` URL;去首尾空白与末尾 `/`。保存**不证明**可达、证书可信、已激活或登录成功。 |
| Active instance | 决定前台请求与助手上下文;会话、项目选择按实例隔离。 |
| Selected project | 决定概览、实时日志、资源轮换与通知设置——仍受成员身份与各 API 的角色检查约束。 |

**不要**为复用凭据把另一个部署换到现有保存 URL 后面。修改实例指向或
移除实例时,预期本地会话/上下文会被清理,并明确登录新身份;安全存储
清理失败是**需要解决的错误**,不是"继续用不确定身份"的理由。

## Home:概览与实时证据

- 概览默认 **24h**,窗口可选 `1h`/`24h`/`7d`/`30d`;用 Refresh 获取新
  样本并阅读时间戳。Home 展示流量、失败端点、调度、执行与运行;切换
  实例/项目/窗口会使旧请求失效,较慢的旧响应**不应**覆盖新视图。
- 实时日志是**独立流**:启动后拿到的是实时事件,不是历史导出;界面最多
  保留 **200** 行;切换项目或离开 Home 即停止。历史过滤等操作见
  [CLI 日志](../cli/logs.md)。服务端拒绝的请求也可能有执行记录——即使
  脚本没有运行。
- 服务端返回 `unauthorized` 会让应用回到登录,而不是保留一个名义上
  已登录的界面;单纯网络错误**不证明**账号被撤销。[Widget 行为](widgets.md)
  另有说明:缓存的 Widget 数字不等于打开着的 Home 连接。

## 轮换资源凭据

**Settings → Project → Resources** 刻意比控制台完整资源编辑器窄:显示
资源的限定名称、类型与已声明的秘密字段名——**不回显**已存秘密值,也
不编辑任意 `plain` 字段。PATCH 需要项目 Owner/Admin/Developer;能**看到**
条目不代表能**修改**。

1. 选择项目与资源,注意其 folder 限定名称。
2. 只填要替换的字段:未触碰字段会**省略**,服务端保留现值。
3. 输入后又清空的字段发送为 `""`——这是**有意清空**,不是省略;各类型
   验证可能拒绝无效凭据组合。
4. 保存后按获准执行的[资源类型验证流程](../assets/resources/index.md)
   检查——保存成功**不是**上游连接测试。
5. 考虑依赖与回滚需要后,再在签发方停用旧凭据。

Cancel 关闭草稿、不发送 PATCH。**不要**把提供商秘密粘进助手或诊断日志;
这个管理视图的脱敏不会消除
[1.1 脚本资源投影的限制](../overview/concepts.md)。

## 助手配置与批准

- 助手是**交互式客户端能力**,不是服务端定时工作流引擎。提供商配置与
  key 存在应用本地、由各保存实例共用;key 按提供商分槽保存;它们**不会**
  自动变成项目 `llm` 资源的凭据。

在 **Settings → Assistant**:

| 设置 | 行为 |
| --- | --- |
| Provider | `anthropic` 或 `openai`(兼容 OpenAI chat/completions)。选择协议**不证明**任意厂商/模型兼容。 |
| Model | 去首尾空白。兼容提供商路径提问前要求非空模型;Anthropic 路径留空用客户端随附默认值。选自己账号可用的模型。 |
| API base URL | 兼容提供商路径使用;提问前要求非空;去空白与末尾 `/`。填该提供商期望的 API 根——保存本身**不**做网络测试。 |
| API key | 按提供商保存的秘密。空白不能保存;新值替换该提供商旧 key。Remove 删除**本地** key——不删提供商账号,也不在签发方撤销。 |

- 分别保存提供商配置与所选提供商的 key。"key saved" **不证明**权限/
  配额/模型访问有效;兼容提供商缺 model/base URL 时,实际请求返回
  `incomplete_config`。请求可能产生费用,并传输提示词与工具结果——
  未经批准**不要**传入敏感材料。
- 助手通过批准卡片提出 **write_script**/**test_run**/**publish** 操作:
  检查其中的实例 URL、项目、源码差异或参数。Approve 在服务端执行;
  Decline 不授权该提案。测试运行可能真实调用资源;**Publish 发布的是
  整个项目所有待发布变更**——不只是聊天里提到的某个脚本;服务端警告
  需要单独确认。切换账号/实例/项目/提供商会使旧助手上下文失效——
  **不会**把原批准转移到新目标。
- 确认界面不是"任意未来动作的授权",也不替代服务端权限;只读工具结果
  仍可能包含私有项目数据并影响模型;返回内容中的**指令不等于**操作
  人员批准。

## 手机通知注册

**Settings → Project → Push notifications** 把本手机绑定到所选项目的
push 资源。这是普通告警/运行通知——**不是**加密 Widget 概览快照。

| 原生构建 | 注册来源 | 必须匹配的资源 |
| --- | --- | --- |
| iOS | APNs device token(需有效 provisioning、通知 entitlement/权限) | APNs 配置的 `push`;环境与 topic 必须匹配构建 |
| Android 源码构建 | JPush SDK registration ID | 匹配的 JPush push 资源与应用设置 |
| Mac 桌面 | 无手机注册 SDK | **不支持**手机推送注册 |

- 项目必须**已有**适用资源。原生 token 未到达导致空 registration ID 时,
  是可重试的 `not_ready`——**不是**虚构的成功;provisioning 或 APNs
  注册错误需修正原生构建/账号设置。Enable 注册本手机——**不证明**
  提供商已接受消息或设备已收到。不要因为列表里有某个资源就选不匹配的
  提供商。
- 退役绑定前先 Disable;退出会尝试按所属账号清理。**切换项目不是发送
  测试通知的许可。**真实投递与提供商清理需明确启用,详见
  [Push 资源](../assets/resources/push.md)。

## 存储、失败与清理

- **Settings → About** 显示部署与存储自检。**不要**把原生凭据存储失败
  误判为服务端密码错误:按报告的存储状态处理;存储降级或仅临时保存时,
  **不能**承诺重启后仍保留登录。**不要**把原始安全存储内容复制进支持
  工单。

| 现象 | 核对与恢复 |
| --- | --- |
| 没有项目 | 核对实例、平台身份与成员关系;用控制台或 CLI 创建/管理项目 |
| 概览不可用 | 核对设备侧 DNS/网络/TLS、激活、成员与所选项目;**不要**用零替代缺失数据 |
| 资源保存被拒绝 | 检查有效项目角色与字段验证;列举权限不是修改权限 |
| 助手没有可用提供商 | 按要求保存 provider/model/root/key,在不暴露 key 的前提下验证账号权限 |
| 批准卡片指向意外项目 | Decline,修正实例/项目后重新发起提案 |
| Push 显示 unknown/not ready | 区分"状态读取失败"与"原生注册未完成";查具体错误与提供商是否匹配 |

共享或退役设备:停用适用通知绑定 → 逐个账号退出 → 按需移除实例;应用
本地提供商 key 单独检查。卸载应用**不保证**撤销服务端会话、清除
Keychain、删除项目资产或撤销提供商凭据;系统已渲染的 Widget 图像可能
保留到下一次重绘。
